# Stick Figure Jumping Widget

This game is a recreation of the game Doodle Jump done with ASCII characters and typescript. It can be embedded within any website to allow users to play a little game. **Currently a work in progress**



## In Progress:
- game controls
	- start
	- pause
	- player loses once it falls to the floor after they start playing
	- replay
	- some sort of scoring

## Notes:
- widget must be placed inside element with id `asc-engine-layer-container`
